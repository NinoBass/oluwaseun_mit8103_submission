D1  LOST UPDATE on inventory.qty_on_hand (two warehouse clerks record a sale)
==============================================================================

(a) Naive application logic, READ COMMITTED: read value, compute in app, write value back
  0.143s  [   A   ]  SELECT qty_on_hand -> 25
  0.143s  [   B   ]  SELECT qty_on_hand -> 25

  0.187s  [   B   ]  SELECT ... FOR UPDATE  (must wait for A)

(c) Fix 2 - let the DBMS do the arithmetic: UPDATE ... SET qty = qty - 1 (READ COMMITTED)
  0.847s  [   A   ]  UPDATE qty_on_hand = qty_on_hand - 1  (not yet committed)
