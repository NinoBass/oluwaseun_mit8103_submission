######## R5  Flash sale in Redis: 40 buyers, 25 units (compare Portfolio 3, test D5) ########
GET -> check in app -> SET                           success=40  stock left=23  -> WRONG (40 sold + 23 left != 25)  (22 ms)
DECR (+ INCR compensation)                           success=25  stock left= 0  -> CORRECT  (16 ms)
Lua script: check + DECRBY + SADD buyer, atomically  success=25  stock left= 0  -> CORRECT  (15 ms)
Redis executes each command / script on one thread, so DECR and Lua are atomic without locks.
Design: Redis gates the stampede in milliseconds; only the 25 winners call place_order() in PostgreSQL,
which stays the system of record (Redis here runs without persistence: --save '' --appendonly no).
